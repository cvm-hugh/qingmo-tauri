# 轻墨 Markdown 编辑器

轻墨是一款基于 Tauri 2 的本地 Markdown 编辑器。当前主线源码为 **2.3.19**。

## 当前源码

源码位于仓库根目录：`src/`、`src-tauri/`、`package.json` 和 `package-lock.json`。版本号以 `package.json`、`src-tauri/Cargo.toml` 与 `src-tauri/tauri.conf.json` 为准。

主要能力包括 Markdown 源码编辑与预览、富文本粘贴、任务列表、表格、图片插入、PDF/Word 导出和主题支持。逐版说明和交接文档以仓库根目录中的 `轻墨2.3.*` 文档为准。

## 获取源码与构建

需要 Node.js、Rust 和 Tauri 2 的构建环境。

```sh
npm install
npm run dev
```

构建桌面应用：

```sh
npm run build
```

## 字体资源

`src/fonts/` 字体文件暂未上传。源码中的自定义字体声明仍保留；缺少相应字体时，界面会回退到系统字体。若需复现包含自定义字体的完整显示效果，请按各字体的授权条件自行取得字体文件后放入 `src/fonts/`。
